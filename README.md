# Todo App

A simple Todo mobile app built with **Expo (React Native) + TypeScript**.

## Features

- Add, complete and delete todos
- Filter by All / Active / Done
- Clear all completed todos
- Todos are saved on the device (AsyncStorage), so they survive app restarts

## Tech stack

| Layer | Choice |
| --- | --- |
| Framework | Expo SDK 58 / React Native |
| Language | TypeScript |
| Storage | `@react-native-async-storage/async-storage` |

## Run it

```bash
npm install
npx expo start
```

Then scan the QR code with the **Expo Go** app on your Android or iPhone, or press `a` for an Android emulator / `w` for the web.
